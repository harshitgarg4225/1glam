Availability & Booking Page

Controls your public booking page. Clients can only request dates that fit these rules.

WhatsApp only allows automated business-initiated messages via an approved template. Create templates in Meta Business Manager.
Booking Request Template — sent when client submits the booking page. Variables: {{1}} client name, {{2}} event type, {{3}} event date.
Approval Notification Template — sent when you click Approve on a lead. Variables: {{1}} client name, {{2}} event date, {{3}} quoted price.
Pre-Event Reminder Template — auto-sent at 8 AM UTC each day. Variables: {{1}} client name, {{2}} event date, {{3}} event time. Set "Remind X Days Before" to control when (e.g. 7,1 = one week and one day before).
Review Request Template — auto-sent the set number of days after the event. Variables: {{1}} client name, {{2}} business name, {{3}} Google review link. Leave "Auto Review Request" blank to turn it off.
Clients also get a "Confirm on WhatsApp" button on the booking page, which works without any template.

Service Descriptions & Add-ons

Add a description and optional add-ons to each service shown on your public booking page. Add-ons format: Name:Price comma-separated, e.g. Hair Styling:2000, False Lashes:500. Leave blank to hide.

Sheet Protection

Enabling protection applies a read-only lock to your Google Sheet in Drive — it shows a padlock icon and prevents accidental edits or moves by anyone with access. The file owner can still remove the restriction from Drive directly.

If your sheet was deleted, use Recover Sheet to re-link the best matching sheet in your Drive, or create a fresh one if none is found.
